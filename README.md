# Global Social Media Growth Analysis

## Project Overview
This project presents an interactive Power BI dashboard analyzing
global social media growth, engagement, and trends across different
regions and countries.

## Tools Used
- Power BI
- DAX
- Power Query
- Excel

## Key Analysis
- Global social media growth
- User engagement
- Regional performance
- Country-wise analysis
- Social media trends

## Dashboard
The Power BI dashboard provides interactive visualizations and
insights into global social media performance.
